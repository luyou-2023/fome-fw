1. 顶层文件说明

文档类

CHANGELOG.md / CHANGELOG.rusefi.md：项目更新记录。

DEVELOPER.md：开发者说明文档。

Doxyfile / DoxygenLayout.xml：用于生成文档的 Doxygen 配置。

构建相关

Makefile、common.mk：主工程和通用编译规则。

脚本

check_illegal_conversion.sh：代码或配置检查脚本。

2. bootloader（启动加载器）

负责 MCU 启动、固件烧写与升级。

核心源码

bootloader_main.cpp：启动入口。

bootloader_stubs.cpp：占位或测试 stub。

OpenBLT 子模块

openblt_chibios：封装了 OpenBLT 升级协议与 ChibiOS 兼容层。

openblt_flash*.cpp：不同 MCU 的 Flash 写入实现。

openblt_net.cpp / openblt_usb.cpp：网络和 USB 升级接口。

types.h：通用类型定义。

支持板和 README

各种 board 支持及说明文档。

3. config（配置与板级定义）

boards/
每块 ECU 板都有自己的配置：

board_configuration.cpp / board.mk：板级初始化、引脚配置。

connectors/：引脚定义和物理接线图 (.yaml/.jpg)。

prepend.txt：编译前添加的通用代码或宏。

knock_config.h / trigger_scope_config.h：敲缸与触发信号相关配置。

compile_*.sh / .bat：针对不同板的编译脚本。

板级差异

支持多种 MCU（STM32F4/F7/H7 系列）、多种车系（Mazda, BMW, Ford 等）。

使用 meta.h 文件存储板元信息（如 resisters 表示硬件 ID）。

4. engines（引擎模型）

每个引擎对应一组 .cpp + .h 文件，描述特定引擎的 ECU 行为。

engine_template.cpp/h：引擎模板。

特定车型实现，如 mazda_miata.cpp/h、bmw_m73.cpp/h。

包含 Lua 脚本支持（.lua 文件），用于自定义逻辑或映射。

5. controllers（控制器逻辑）
   5.1 actuators（执行器）

控制车辆执行器，如：

ac_control（空调）、boost_control（增压）、electronic_throttle（电子节气门）、vvt（可变气门正时）。

包含状态文件（.txt）和生成头文件（*_generated.h）。

5.2 algo（算法）

ECU 算法实现：

airmass（空气流量计算）、fuel（燃油计算）、ignition（点火逻辑）。

launch_control、antilag_system。

包含生成文件和默认脚本 (defaults/，default_*.cpp)。

5.3 engine_cycle（发动机周期）

管理点火、喷油、敲缸控制等循环逻辑：

fuel_schedule.cpp、spark_logic.cpp、knock_controller.cpp。

6. console（通信与调试）

binary/：二进制协议处理，如 tunerstudio.cpp/h。

binary_log/：记录和解析日志。

console_io.cpp/h：通用 IO。

wifi_console.cpp / usb_console.cpp：调试接口。

支持 CAN 总线和实时数据 (can/ 子目录)。

7. core（核心框架）

核心循环、状态机、错误处理：

main_loop.cpp、state_sequence.cpp。

engine_module.h：模块化 ECU 设计。

big_buffer.cpp：可能用于高速数据缓存。

8. gauges（仪表盘）

仪表逻辑：

malfunction_indicator、speedometer、malfunction_central。

用于在 ECU 或外部显示故障和速度数据。

9. Lua 脚本支持

lua/ 目录：

CAN 过滤器 can_filter.cpp/h。

示例脚本 examples/ 提供控制策略或测试逻辑。

增强了 ECU 的可扩展性和自定义逻辑能力。

10. MCU 特性文件

stm32f4ems/、stm32f7ems/、stm32h7ems/ 下的 efifeatures.h：

每个 MCU 系列特有功能配置。

11. 总结分析

模块化设计

按板、引擎、执行器、算法、循环、通信分层。

支持多板、多车系、多引擎模型。

生成文件与默认模板

_generated.h 和 .txt 文件用于状态、表格和映射自动生成。

Lua 脚本和默认文件保证 ECU 可扩展性。

硬件抽象

board_configuration.cpp + connectors/*.yaml 完全抽象硬件。

meta.h 提供硬件 ID 与元信息。

调试与通信

Console + CAN + USB + WiFi 调试接口丰富。

二进制日志模块支持快速数据记录。

Bootloader 与升级

OpenBLT + ChibiOS 完整固件升级和 Flash 写入机制。

适用范围

面向多种汽车品牌、引擎类型和定制 ECU 硬件。
