# 执行器子系统文档

## 1. 架构概览

执行器子系统负责将控制算法的计算结果转换为物理动作。执行器通过PWM、GPIO或H桥等硬件接口驱动发动机的执行机构。

```
控制算法 → 执行器控制器 → 硬件输出 → 执行机构
 (PID/查表/前馈)    (限幅/安全保护)   (PWM/GPIO/CAN)
```

## 2. 电子节气门 (ETB) (`actuators/electronic_throttle.cpp`)

### 闭环控制架构

```
目标位置计算 ← SPD位置传感器
  ↓
Open Loop (前馈)
  + PID (闭环)
  = 输出占空比
  ↓
H桥电机驱动
  ↓
节气门位置传感器(冗余) → 位置反馈
```

### 目标位置计算流程

```
getSetpointEtb():
  1. 读踏板位置传感器 (冗余校验)
  2. 踏板→目标节气门位置查表 (pedalToTpsTable, 3D: 踏板位置 × RPM)
  3. 扭矩模型处理 (如果启用)
  4. 逐个节气门修整 (EtbController2)
  5. ETB限速器 RPM达到限制时线性关闭节气门
  6. 钳位到最小/最大位置
```

**踏板→节气门映射**: 允许配置非线性映射，例如踏板前50%行程对应节气门0-70%开度（城市驾驶更精确），后50%对应70-100%（激烈驾驶响应更快）。

### 前馈控制 (Open Loop)

使用 `etbBiasBins`/`etbBiasValues` 表，对目标位置查询所需占空比。这是基于弹簧力和气流力的静态补偿——节气门翻板在某一个开度需要一定占空比才能克服弹簧力维持位置。

**为什么需要前馈**: 纯PID反馈控制总有延迟，当快速踩下油门时，PID需要时间积分误差才能产生足够的输出。前馈可以立即提供大部分所需占空比，PID只负责修正误差，大幅提高响应速度。

### PID闭环控制

```c
getClosedLoop(target, observation)
  // 标准PID: u(t) = Kp*e(t) + Ki*∫e(t)dt + Kd*de(t)/dt
  // 积分分离: 大误差时减小Ki防止超调(积分饱和)
  // 卡滞检测: 如果持续误差过大，判定为机械卡滞
```

### 自动调谐

基于 **Åström-Hägglund 继电反馈** 方法：
```
1. 强制节气门在目标点附近做bang-bang振荡
2. 测量振荡的极限增益(K_u)和极限周期(T_u)
3. 使用Ziegler-Nichols规则计算PID参数
4. 无需手动调节PID参数——适合不同的节气门体
```

### 自校准

```c
autoCalibrateTps():
  phase = Open   → 全开 → 记录ADC值为最大值
  phase = Close  → 全关 → 记录ADC值为最小值
  // 可以独立运行，不影响发动机运行
```

### 安全设计

- **冗余TPS传感器**: 两个独立的电位器，读数必须一致
- **冗余踏板传感器 (PPS)**: 主副传感器交叉校验
- **卡滞检测**: 误差超阈值持续超过超时时间 → 进入跛行模式
- **Lua禁用**: Lua脚本可以设置 `etbLuaDisable` 标志
- **输出限幅**: 电机占空比限制在 ±0.9 (90%)

## 3. 怠速控制 (`actuators/idle_thread.cpp`)

### 怠速状态机

```
Phase: Cranking → CrankToIdleTaper → Idling ↔ Coasting / Running
```

| 阶段 | 检测条件 | 控制策略 |
|------|---------|---------|
| Cranking | RPM低于运行阈值 | 开环: 固定IAC位置 × CLT修正 |
| CrankToIdleTaper | 起动后转数衰减期内 | 从起动位置→怠速位置渐变 |
| Idling | 低于进入RPM, 关闭节气门, 车速低 | PID闭环 + 开环 + 点火定时微调 |
| Coasting | 高于退出RPM, 松开油门 | 查iacCoasting表或开环 |
| Running | TPS高于怠速阈值 | 开环: 基本位置 + 修正 |

### 目标RPM计算

```c
getTargetRpm(clt):
  // 1. 查 cltIdleRpm 表 (水温→目标怠速)
  // 2. 添加空调AC RPM提升 (acIdleRpmBump)
  // 3. 添加Lua RPM修正
  // 输出: 启用/禁用怠速控制的RPM阈值 (带迟滞)
```

**为什么使用迟滞**: 如果进入和退出怠速的RPM阈值相同，当RPM在阈值附近波动时会导致状态频繁切换（抖振）。使用不同的进入/退出阈值（退出RPM > 进入RPM）提供迟滞带，确保状态切换稳定。

### PID闭环控制

- 仅在 `Idling` 阶段启用
- 使用专用 `idleRpmPid` PID控制器
- 离开Idling阶段时复位积分器，特别是负积分（过多积分可能导致回到Idling时进气不足）

### 点火定时微调

```c
getIdleTimingAdjustment(rpm, rpmRate):
  // 备用PID控制器 (idleTimingPid)
  // 通过微调点火提前角影响怠速RPM
  // 提前点火 → RPM上升
  // 推迟点火 → RPM下降
  // 比IAC响应更快 (点火变化立即影响缸内燃烧)
```

## 4. 增压控制 (`actuators/boost_control.cpp`)

### 控制策略

- 目标增压值查表(3D: RPM × 负荷)
- PID闭环控制废气旁通阀占空比
- 开环前馈(目标增压→基础占空比)
- 限压保护

## 5. 交流发电机控制 (`actuators/alternator_controller.cpp`)

- 目标电压闭环控制
- PID调节励磁电流 (通过PWM)
- 电压补偿: 根据温度/负载调整目标电压

## 6. VVT控制 (`actuators/vvt.cpp`)

- 目标VVT角度查表(3D: RPM × 负荷)
- PID控制凸轮轴相位机油控制阀(OCV)
- 支持进气/排气VVT

## 7. 空调控制 (`actuators/ac_control.cpp`)

- 空调请求检测 (AC按钮 + 压力开关)
- 压缩机离合器继电器控制
- 怠速提升补偿 (开空调时增加怠速进气量)
- 发动机保护: 大负荷/高温时自动断开空调

## 8. 主继电器控制 (`actuators/main_relay.cpp`)

- 控制系统主继电器的开关
- 发动机关闭后保持延时（散热风扇继续运行）
- 故障检测和自动关机

## 9. PWM输出框架 (`actuators/gppwm/`)

通用PWM输出系统，将任何传感器值映射到PWM占空比：
- 输入: 传感器值 (如CLT、MAP)
- 映射: 2D或3D查表
- 输出: PWM占空比 (驱动风扇、燃油泵、等)

## 10. 执行器安全策略

### 跛行模式 (Limp Mode)

当检测到严重故障时：
1. **电子节气门**: 断开电机电源 → 节气门靠弹簧回到"跛行位置"（约15%开度）
2. **点火**: 限制最大点火提前角和RPM
3. **燃油**: 加浓混合气防止爆震
4. **增压**: 打开废气旁通阀泄压

### 看门狗

- **ECU看门狗**: 如果主循环停滞超过100ms，软件看门狗触发安全关闭
- **硬件看门狗**: 如果ECU完全死机，硬件看门狗触发系统复位

### 初始化安全

- 在 `initHardware()` 之前，执行器输出引脚处于安全状态（高阻抗）
- 启动时检查节气门位置，确保电机能正常运动
- 如果检测到异常，阻止发动机启动
