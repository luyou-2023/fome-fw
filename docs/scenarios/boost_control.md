# 增压控制场景分析

## 1. 场景描述

控制涡轮增压器的废气旁通阀或可变几何涡轮(VGT)执行器，调节发动机的进气增压压力。

## 2. 控制架构

```
目标增压 (查表: RPM × 负荷)
  ↓
开环前馈 (目标→基础占空比)
  ↑ ↓
闭环PID (实际MAP → 修正占空比)
  ↓
PWM输出 → 废气旁通阀执行器 → 涡轮转速 → 进气压力
  ↑
MAP传感器 (实际进气压力)
```

## 3. 目标增压计算

- 3D表: RPM × 负荷 → 目标MAP
- 大气压力修正: 海拔补偿 (海平面目标增压 > 高海拔)
- 增压限制: 根据进气温度、冷却液温度、爆震动态降低目标

## 4. 保护策略

- 进气温度过高 → 降低目标增压
- 冷却液温度过高 → 降低目标增压
- 爆震检测 → 降低目标增压
- 超过极限增压 → 立即打开废气旁通阀

## 5. 执行器类型

| 类型 | 控制方式 | 特点 |
|------|---------|------|
| 废气旁通阀 (Wastegate) | PWM电磁阀 | 简单可靠, 常用 |
| 可变几何涡轮 (VGT) | PWM执行器 | 响应快, 成本高 |
| 电子泄压阀 | 电机驱动 | 精确控制 |
