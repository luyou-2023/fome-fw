# VVT 控制场景分析

## 1. 场景描述

可变气门正时(VVT)系统通过控制凸轮轴相位调节器(OCV)的机油压力，改变进气/排气门开启和关闭的正时，优化发动机在不同工况下的性能。

## 2. 控制架构

```
目标VVT角度 (查表: RPM × 负荷)
  ↓
PID控制器 → PWM输出 → OCV机油控制阀
  ↓
凸轮轴相位传感器 (反馈)
  ↑
曲轴位置传感器 (参考)
```

## 3. 角度检测

```c
// VVT位置通过凸轮轴齿与曲轴基准的角度差计算:
// vvtAngle = camToothAngle - expectedCamToothAngle
// 
// 曲轴同步后，已知每个曲轴角度对应的凸轮轴理论位置
// 实际凸轮齿出现的角度与理论角度的差 = VVT位移
//
// VVT读超时: 1秒无新数据 → 返回错误
```

## 4. 策略

- **低速/低负荷**: 进气门提前关闭(早关) → 减少气门重叠 → 提高怠速稳定性
- **中速/中负荷**: 进气门推迟关闭(晚关) → 进气惯性充气 → 提高容积效率
- **高速/高负荷**: 排气门提前打开 → 排气更充分 → 提高功率输出
- **部分负荷**: 内部EGR(气门重叠) → 减少泵气损失 → 提高燃油经济性

## 5. 凸轮相位同步

在发动机起动时，凸轮轴传感器帮助识别曲轴当前处于哪个行程：
```c
// 无VVT: 曲轴转两圈才能确定相位 (360°曲轴=不确定，720°曲轴=确定)
// 有VVT: 一个凸轮齿信号即可确定当前是哪个气缸的压缩行程
// syncAndReport(divider, remainder) → 调整曲轴相位基准
```

## 6. 限制

- 最大VVT执行范围（硬件限制）
- 最低RPM（机油压力足够推动凸轮相位器）
- 传感器超时保护
- 初始化校准
