# 起动场景分析

## 1. 场景描述

发动机从静止到开始旋转并自主运行的过程。涉及起动电机拖动曲轴旋转、触发信号产生、燃油喷射建立和点火。

## 2. 数据流

```
1. 钥匙 ON → ECU上电
2. 起动机啮合 → 曲轴旋转 → 触发信号产生
3. hwHandleShaftSignal() (中断) → TriggerCentral解码
4. RPM从0开始增加 → 超过起动识别阈值
5. 主继电器吸合 → 燃油泵启动
6. 喷油嘴喷射起动油量
7. 点火线圈产生火花
8. 气缸点燃 → RPM上升 → 超过起动转速
9. 起动电机脱开 → 进入正常运行状态
```

## 3. 关键代码路径

### 触发同步

```c
// 发动机首次转动时，触发解码器需要检测同步点
// 同步点 = 曲轴触发轮上的特殊间隙(缺齿/长齿)
// 首次完整周期后，解码器确认曲轴相位
// 然后才能知道哪个气缸在压缩上止点
```

### 起动燃油计算 (`fuel_math.cpp:getCrankingFuel3`)

```c
// 三因素修正模型:
// 1. 时间衰减: 转数从1开始递增，燃油量递减
//    (模拟气缸壁油膜逐渐建立)
// 2. 水温修正: -30°C时喷射量可达正常值的10倍
//    (低温燃油蒸发极差)
// 3. TPS修正: 踩油门时增加燃油
//    (清缸模式/加速辅助)
```

### 怠速目标建立

起动后进入 `CrankToIdleTaper` 阶段，IAC位置从起动值渐变到怠速值，渐变时间由 `afterCrankingIACtaperDuration` 配置。

## 4. 时序

```
T=0ms:   起动机开始拖动 (RPM 0→200)
T=50ms:  触发解码器同步完成
T=100ms: 第一个喷射事件
T=150ms: 第一个点火事件
T=300ms: 第一个气缸燃烧 (RPM 200→600)
T=1000ms: RPM > 起动完成阈值 → 起动机脱开
T=3000ms: 进入正常怠速控制
```

## 5. 设计权衡

- **为什么要等到同步完成才喷油**: 如果相位未知，可能在排气行程喷油，燃油直接排出排气管，既浪费又可能造成排气管放炮。
- **起动油量为什么远超理论值**: 冷机时燃油在冷气缸壁上凝结，真正参与燃烧的只有很小部分。需要过量喷射才能形成可燃混合气。
- **转数衰减的工程直觉**: 第一转需要最大加浓以建立缸壁油膜；一旦油膜建立（几转之后），随后的转数只需保持即可，燃油量逐渐减少到接近正常值。
