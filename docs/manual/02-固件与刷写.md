# 第二章：固件与刷写

## 2.1 获取固件

固件发布在 [GitHub Releases](https://github.com/FOME-Tech/fome-fw/releases)。

### 固件文件说明

| 文件 | 说明 |
|------|------|
| `fome.bin` | 完整镜像（bootloader + 固件），用于空白 ECU |
| `fome_update.srec` | 更新镜像，通过 bootloader 刷写 |

**自行编译：**
```bash
cd firmware/config/boards/proteus
./compile_proteus_f7.sh
```
输出文件在 `firmware/deliver/`。

**代码位置：** `firmware/config/boards/<board>/` — 各主板的编译脚本

## 2.2 通过 FOME Console 更新

1. 确保 TunerStudio 未运行
2. 连接 ECU 到电脑
3. 打开 FOME Console → 自动检测主板
4. 点击 "Update Firmware"
5. 等待绿色提示 → 断开重连 ECU

## 2.3 通过 DFU 模式恢复

当固件损坏无法正常通信时：

1. 断开 ECU 电源
2. 按住 BOOT 按钮（或短接 BOOT 引脚）
3. 连接 USB 到电脑
4. 松开 BOOT 按钮
5. FOME Console 会显示 DFU 模式 → 刷写固件

## 2.4 TunerStudio 设置

1. 打开 TunerStudio → 新建项目 → Detect
2. 选择 ECU 对应的 COM 口
3. 加载 `.ini` 配置文件（固件包内或 USB 设备中）
4. 选择显示单位：Lambda（推荐）或 AFR

### 关于 FOME 与 rusEFI 的关系

当前 FOME 是 rusEFI 的一个分支，现有主板同时兼容 rusEFI 和 FOME。随着未来代码变更，兼容性可能变化。详见 [FOME 声明](https://www.fome.tech/announcements)。

**代码处理流程：**
- `firmware/console/binary/tunerstudio.cpp` — TunerStudio 通信协议实现
- `firmware/console/binary/tunerstudio_commands.cpp` — 命令处理（读/写配置、执行指令）
- `firmware/console/eficonsole.cpp` — FOME Console 控制台界面
