# 第八章：提示与技巧

## 8.1 上电循环

每次更改 ECU 配置后建议断开再接通电源（断电重启）。
**例外：** 调校表格（VE 表、点火提前角表等）可以热更新，无需重启。

## 8.2 必须使用主继电器

主继电器是 FOME ECU 系统的关键组件：
- 保护 ECU 免受电源浪涌和电压尖峰伤害
- 提供稳定的电源连接，减少电气干扰
- 确保点火开关关闭后 ECU 能安全关机

**代码位置：** `firmware/controllers/actuators/main_relay.cpp` — 主继电器控制逻辑
```c
// 主继电器在点火开关 ON 时吸合
// 发动机关闭后保持延时（散热风扇继续运行）
// 检测到故障时自动断开
```

`firmware/controllers/algo/engine.cpp:432` — `isMainRelayEnabled()`：
```c
// 如果未配置主继电器控制，默认认为始终开启
return enginePins.mainRelay.getLogicValue();
```

## 8.3 +12V 供电下校准传感器

仅通过 USB 供电时，+5V 传感器参考电压可能低于正常值（USB 5V 经过板载稳压器有压降）。
建议在 +12V 供电（连接汽车电池）下进行传感器校准，否则可能导致读数偏差。

## 8.4 表轴规则

所有 2D/3D 表的轴必须严格**单调递增**（例如 1, 2, 3；不能 1, 1, 3；不能 1, 3, 2）。

**为什么：** 插值算法假设轴值单调递增。如果轴值乱序，插值结果不可预测。

**代码位置：** `firmware/util/math/interpolation.cpp` — 插值算法实现：
```c

// 假设数组已排序递增
// 如果未排序，二分查找结果错误 → 插值错误
```

## 8.5 错误代码查询

当 TunerStudio 显示错误时，对照固件中的错误码定义：

**代码位置：**
- `firmware/controllers/algo/obd_error_codes.h` — OBD 标准错误码
- `firmware/controllers/algo/rusefi_enums.h` — RUSEFI 自定义错误码

常见错误：
- `CUSTOM_ERR_UNEXPECTED_SHAFT_EVENT` — 触发配置错误
- `CUSTOM_PRIMARY_DOUBLED_EDGE` — 触发信号噪声（加倍边沿）
- `CUSTOM_ERR_ZERO_E0_MULT` — 燃油加浓系数配置为零
