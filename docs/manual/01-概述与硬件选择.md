# 第一章：概述与硬件选择

## 1.1 什么是 FOME

FOME (Free Open Motorsports ECU) 是一个开源车辆控制生态项目，专注于安全性、可靠性和可持续性。它源于 rusEFI 项目，旨在提供符合汽车行业标准的开源 ECU 解决方案。

**核心特性：**
- 基于 STM32 微控制器（32位 ARM Cortex-M）
- 运行 ChibiOS/RT 实时操作系统
- 支持 Speed-Density、MAF、Alpha-N 多种进气测量方式
- 支持电子节气门（ETB）、VVT、增压控制等高级功能
- 通过 TunerStudio 进行调校和诊断
- 内置 Lua 脚本引擎支持自定义逻辑

## 1.2 硬件架构

### 大脑 (Brain) — Polygonus

所有 FOME ECU 使用相同的核心模块 **Polygonus**，包含：
- STM32 MCU（F4/F7/H7 系列）
- 电源管理电路
- 驱动芯片（点火线圈、喷油器、H桥等）
- CAN 收发器

**代码位置：** `firmware/hw_layer/ports/stm32/` — STM32 系列硬件抽象层代码。
- `stm32_common.cpp`: 通用 STM32 初始化
- `stm32_pins.cpp`: GPIO 引脚映射
- `stm32_adc_v2.cpp` / `stm32_adc_v4.cpp`: ADC 采样配置

### 基板 (Baseboard)

不同车型有专用的基板：

| 基板 | 适用车型 | 特点 |
|------|---------|------|
| BMW | E36 M50TU/M60 | 即插即用 |
| Miata | NA/NB MX5 | 支持 1.6/1.8/VVT/涡轮 |
| Harley | 2021+ 哈雷 | NMSTEC 出品 |
| Universal | 通用 | VAG 120 针接口，8缸顺序喷射 |
| Honda | VTEC | 开发中 |

**代码位置：** `firmware/config/boards/` — 各主板的引脚配置和硬件初始化。
- `proteus/board_configuration.cpp`: Proteus 主板配置
- `hellen/hellen_common.cpp`: Hellen 系列共享配置
- `microrusefi/board_configuration.cpp`: microRusEfi 配置

## 1.3 启动流程

ECU 上电后的初始化序列：

```
1. 硬件复位 → ChibiOS 内核启动
2. runRusEfi()              [rusefi.cpp]
   ├── loadConfiguration()  [从 Flash 读取配置]
   ├── initHardware()       [ADC/PWM/CAN/GPIO 等外设初始化]
   ├── startLua()           [启动 Lua 脚本引擎]
   └── initMainLoop()       [启动 1000Hz 主控制循环]
3. 主循环等待触发信号
```

**代码处理流程：**
- `firmware/rusefi.cpp:157` — `runRusEfi()` 入口函数，启动所有子系统
- `firmware/controllers/core/main_loop.cpp:38` — `PeriodicTask()` 1000Hz 主循环
  - 500Hz: ADC 采样 + 电子节气门控制
  - 250Hz: 燃油/点火计算
  - 20Hz: 慢速传感器/看门狗
