# 第七章：燃油方法选择

## 7.1 三种空气量模型

ECU 计算喷油量的第一步是确定进入气缸的空气量。FOME 支持三种模型：

### Speed-Density（速度密度法）— 最常用

**原理：** 利用理想气体状态方程，通过 MAP 传感器测量进气歧管压力，结合 VE 表和 IAT 计算空气量。

```
airMass = MAP × VE × displacement / (R × IAT_K)
```

**优点：** 不需要 MAF 传感器，成本低，进气管路无额外阻力
**缺点：** 需要准确的 VE 表，对气门重叠大的发动机精度下降

**代码位置：** `firmware/controllers/algo/airmass/speed_density_airmass.cpp`

### MAF（空气质量流量计）

**原理：** 直接测量进入发动机的空气质量流量。

```
airMass = MAF_flowRate × (60 / RPM / 2)
```

**优点：** 直接测量，无需 VE 表，不受气门重叠影响
**缺点：** 对进气管路泄漏敏感，大流量时进气阻力大

**代码位置：** `firmware/controllers/algo/airmass/maf_airmass.cpp`

### Alpha-N

**原理：** 直接用 TPS（节气门位置）和 RPM 查表获取空气量。

```
airMass = alphaNTable(TPS, RPM)
```

**优点：** 适用于极端凸轮轴重叠导致 MAP 信号失真的情况
**缺点：** 无法补偿海拔和气温变化

**代码位置：** `firmware/controllers/algo/airmass/alphan_airmass.cpp`

## 7.2 模型选择

| 条件 | 推荐模型 |
|------|---------|
| 原厂进气道，带 MAP 传感器 | Speed-Density |
| 已有 MAF 传感器，无 VE 表 | MAF |
| 高角度凸轮轴，ITB（独立节气门） | Alpha-N |
| 自定义 | Lua |

**代码位置：** `firmware/controllers/algo/fuel_math.cpp:141` — `getAirmassModel()` 根据配置选择模型：
```c
switch (mode) {
    case LM_SPEED_DENSITY: return &sdAirmass;
    case LM_REAL_MAF:      return &mafAirmass;
    case LM_ALPHA_N:       return &alphaNAirmass;
    case LM_LUA:           return &(getLuaAirmassModel());
}
```

## 7.3 目标空燃比

目标 Lambda 表（RPM × 负荷）定义了每个工况点的目标空燃比：

| 区域 | Lambda | 场景 |
|------|--------|------|
| 巡航 | 1.00 | 理论空燃比，三效催化器效率最高 |
| 大负荷 | 0.85-0.90 | 浓混合气冷却燃烧室，防爆震 |
| 减速 | 1.1+ / 断油 | 稀混合气或断油，省油 |
| 起动 | 0.5-0.8 | 极浓，冷起动时需要 |

**代码位置：** `firmware/controllers/algo/fuel/fuel_computer.cpp` — 目标 AFR 查表和应用
