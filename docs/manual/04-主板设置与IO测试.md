# 第四章：主板设置与 IO 测试

## 4.1 初始设置

拿到新主板后的基本步骤：
1. 连接 ECU 到电脑（USB）
2. 打开 TunerStudio → 检测固件
3. 加载对应的车辆预设（Popular Vehicles）
4. 检查输出引脚配置是否正确

**代码位置：**
- `firmware/config/boards/<board>/board_configuration.cpp` — 各主板的引脚功能配置
- `firmware/config/boards/hellen/hellen_board_id.cpp` — Hellen 系列主板自动识别

## 4.2 输入测试

### 触发信号测试
- 使用 TunerStudio 的 Tooth Logger 功能
- 曲轴旋转时观察齿信号是否与触发轮形状一致

**代码处理流程：** `trigger_central.cpp:574` `handleShaftSignal()` → `trigger_decoder.cpp:397` `decodeTriggerEvent()`

### 模拟输入测试
- CLT/IAT/MAP/TPS 等传感器应显示合理的电压或工程量值
- 在 TunerStudio 仪表板中观察

### 开关输入测试
- 刹车开关、离合器开关、AC 请求等
- 可以观察 TunerStudio 中的数字输入状态

**代码位置：** `firmware/controllers/sensors/allsensors.cpp:16` — `initSensors()` 初始化开关消抖。

## 4.4 引脚名称映射

每块主板都有一个自动生成的引脚映射文件：
```
firmware/config/boards/<board>/connectors/generated_ts_name_by_pin.cpp
```

例如 Hellen81 主板：
```c
case Gpio::A6: return "79 - IN_CAM";     // 凸轮轴传感器输入
case Gpio::B0: return "74 - IN_AUX1";    // 辅助模拟输入1
case Gpio::B8: return "23 - IGN_6";      // 点火输出6
case Gpio::C7: return "66 - OUT_COIL_A2";// 线圈驱动 A2
```

这些映射由 `PinoutLogic.java` 根据 YAML 配置文件自动生成，用于 TunerStudio 显示物理引脚功能。
