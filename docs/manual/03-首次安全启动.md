# 第三章：首次安全启动

## 3.1 安全准备

- ⚠️ 首次启动必须有两人配合
- 准备车用灭火器（燃油/电气火灾级别）
- 工作区域通风良好、无易燃物
- 闻到浓烈燃油味立即停止

## 3.2 启动前检查

### 传感器校验

确认以下传感器功能正常且已校准：

| 传感器 | 检查内容 | 代码位置 |
|--------|---------|----------|
| MAP/MAF | 进气压力/流量 | `firmware/init/sensor/init_map.cpp` |
| CLT | 冷却液温度 | `firmware/init/sensor/init_thermistors.cpp` |
| IAT | 进气温度 | 同上，使用 Steinhart-Hart 方程 |
| TPS | 节气门位置 | `firmware/controllers/sensors/tps.cpp` |
| 燃油压力 | 油压传感器 | `firmware/init/sensor/init_fluid_pressure.cpp` |

**代码处理流程—温度传感器：**
```
ADC 电压 → ResistanceFunc 电压→电阻
         → ThermistorFunc Steinhart-Hart 电阻→温度
         → StoredValueSensor 带超时的值存储
```

`firmware/controllers/sensors/converters/thermistor_func.cpp:42` — `configure()` 计算 Steinhart-Hart 系数：
```c
// 三个校准点 (T1,R1)(T2,R2)(T3,R3) 计算 a,b,c
// 1/T = a + b*ln(R) + c*(ln(R))^3
```

### 触发轮信息

必须知道曲轴触发轮的：
- 齿数（如 36-1 = 35 个有效齿）
- TDC 偏移角度

**代码位置：**
- `firmware/controllers/trigger/decoders/trigger_universal.cpp:45` — `initializeSkippedToothTrigger()` 通用缺齿触发轮配置
- `firmware/controllers/trigger/decoders/` — 各品牌专用触发模式

## 3.3 曲轴传感器验证

1. 在 TunerStudio 中禁用燃油和点火
2. 进入 Diagnostics → Tooth Logger
3. 用起动机拖动发动机
4. 确认齿日志正确显示触发轮图案

**代码处理流程：**
```
触发信号 → hwHandleShaftSignal() [hw_layer/digital_input/trigger/]
          → TriggerCentral::handleShaftSignal() [trigger/trigger_central.cpp]
            → isToothExpectedNow() 噪声滤波
            → decodeTriggerEvent() 解码 [trigger/trigger_decoder.cpp]
              → 间隙比同步点检测
              → 齿计数验证
```

`firmware/controllers/trigger/trigger_central.cpp:574` — `handleShaftSignal()` 触发信号处理核心：
```c
// 1. 检查触发波形是否损坏
// 2. 噪声滤波: isToothExpectedNow()
// 3. 触发解码: decodeTriggerEvent()
// 4. 计算下一个预期相位
// 5. 更新 RPM
// 6. 调用 mainTriggerCallback() → 燃油/点火调度
```

## 3.4 TPS 校准

在 TunerStudio 中：
1. Tools → Calibrate TPS
2. 不踩油门 → Get Current（关闭位置）
3. 踩到底 → Get Current（全开位置）
4. Save (Burn)

**代码位置：** `firmware/controllers/sensors/tps.cpp:6` — `grabTPSIsClosed()` / `grabTPSIsWideOpen()`

## 3.5 输出测试

### 燃油泵测试
- Controller → Bench Test & Commands → Fuel Pump
- 应听到燃油泵运转声

### 点火测试（⚠️ 高压危险）
- 测试火花输出，确认线圈工作
- 用火花塞接地观察火花

### 喷油器测试
- 逐一测试各喷油器
- 听"咔嗒"声确认工作

**代码位置：** `firmware/controllers/system/bench_test.cpp` — 台架测试指令处理
- `firmware/controllers/system/injection_gpio.cpp` — 喷油器 GPIO 控制
- `firmware/controllers/system/efi_output.cpp` — 通用输出控制

## 3.6 首次起动

1. 关闭点火 → 断开 USB → 等待 >10 秒
2. 连接 USB → 打开点火 → 等待 TS 连接
3. 确认 Fuel/Ignition 已启用
4. 起动机拖动，观察 RPM（通常 150-400 RPM）
5. 发动机可能需几秒同步 VVT 相位

**代码处理流程—起动判定：**
```c
// firmware/controllers/algo/rpm_calculator.cpp
// RPM 状态机: STOPPED → SPINNING_UP → CRANKING → RUNNING
state == STOPPED     // 2秒无触发事件
     → SPINNING_UP   // 收到触发事件
     → CRANKING      // RPM > 0
     → RUNNING       // RPM > 起动机脱开转速
```

起动燃油逻辑 (`firmware/controllers/algo/fuel_math.cpp:41`)：
```c
// getCrankingFuel3() 三因数修正:
// 1. 转数衰减: 随着转动次数增加逐渐减少
// 2. 水温修正: 冷起动大量加浓
// 3. TPS修正: 踩油门增加燃油
```
